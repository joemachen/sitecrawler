# sitecrawler

Point it at a site. Get every page, every problem, and what to do about it.

```bash
uv run sitecrawler crawl https://example.com -o pages.csv
```

- **User guide** explains each command and column, and (from Phase 2) each audit rule.
- **Project** holds how we work, how the code is organised, and where it is going.
- **API reference** is generated from the code's docstrings.
